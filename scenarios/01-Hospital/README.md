# 🏥 Scenario: Hospital Threat Hunting Lab

## 📖 Mission briefing Background Information 
Dr. Adams is officially scheduled to be attending a medical convention in Hawaii this week. This means all routine chart reviews should originate from expected clinic subnets. However, recent telemetry (remote data tracking) shows some unusual activity patterns. Security analysts must audit the logs across three difficulty tiers to determine unauthorized access, insider threats, and credential tampering.

## 🔍 Network Baseline & Expectations
* **Admin Subnet:** '10.20.1.x' (Doctor's Offices)
* **Nurse Subnet:** '10.20.5.x' (Nurse Stations)
* **Expected behavior:** Routine charting and dosage verification during standard shifts.
